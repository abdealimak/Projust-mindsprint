Layered checks, because none is perfect alone.

  • A phone can beat tab-switch detection, so no single check decides. Each is easy to pass if you know your code and costly to dodge.
  • The result is a confidence level, not a verdict. Retakes are allowed, and the report shows context.
  • Team projects are scored per person. Each member answers their own questions; commit share is shown, never used as a penalty.
  • Private code stays private. Profiles show scores and concepts, never your source.
