# UX profile — Projust

- Theme: light only. Canvas `#F3F5F4`, sheet `#FFFFFF`, one accent `#2F3FD0` (seal blue). Green `#1E8A5A` only for verified.
- Aesthetic reference: Stripe / Notion restraint, certificate "security print" details (guilloché, serials, stamps).
- Motion: 100/150/200/300ms tokens, ease-out in, ease-in out, transform + opacity. One orchestrated hero moment; scroll-scrubbed scenes allowed. No looping decoration.
- Type: Newsreader display, Geist UI, Geist Mono for code/IDs only. Max weights 400/500/600.
- Banned: glassmorphism, gradient CTAs, all-caps eyebrows, single italic accent word in headlines, "→" button suffix, cartoon people, decorative pills on static text.
- Contrast target: WCAG AA.
